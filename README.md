# Glance

Dalamud plugin for [RPHub.co](https://rphub.co) - view and share FFXIV roleplay profiles in-game. Think TRP3, but for XIV.

[Discord](https://discord.gg/rbSWGK9gvT) | [Plugin Page](https://rphub.co/glance)

## Install

1. Dalamud Settings > Experimental > Custom Plugin Repositories
2. Add `https://rphub.co/dalamud/pluginmaster.json`
3. Search "Glance" in the installer

You'll need [Dalamud](https://goatcorp.github.io/dalamud-docs/) and a free [RPHub.co](https://rphub.co) account.

## What it does

- Profile tooltips when you target players, with at-a-glance info for walk-up RP
- Custom nameplate icons, names, and titles for Glance users
- Nearby player discovery with distance
- Chat name replacement with profile names
- Private local notes per character
- Real-time sync between web and plugin
- Console/non-plugin users can link profiles too
