## Install

1. Open **Dalamud Settings** → **Experimental** → **Custom Plugin Repositories**
2. Add the repository URL:
   ```
   https://rphub.co/dalamud/pluginmaster.json
   ```
3. Search **"Glance"** in Plugin Installer

> Requires [Dalamud](https://goatcorp.github.io/dalamud-docs/) and a free [RPHub.co](https://rphub.co) account.

<br/>

## Features

| Feature | Description |
|---|---|
| **Profile Tooltips** | View RPHub profiles by targeting players with "At First Glance" info for walk-up RP |
| **Custom Nameplates** | Unique icons, names, and titles on nameplates for all Glance users |
| **Auto-Discovery** | Automatically finds nearby Glance users and displays distance |
| **Chat Integration** | Replaces character names in chat with their selected profile name |
| **Private Notes** | Save personal notes per character and profile, stored locally |
| **Real-Time Sync** | Edit on the web or in-game — changes sync instantly |
| **Console Support** | Non-plugin and console users can link RPHub profiles to their characters |
